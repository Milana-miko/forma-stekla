# Forma Stekla — статическая версия с email, Telegram и PWA

## Что добавлено

- отправка заявок на email через Web3Forms;
- одновременное уведомление в Telegram через Telegram Bot API;
- секретные ключи хранятся в Netlify, а не в HTML;
- до 3 вложений: JPG, PNG, WEBP или PDF;
- автоматическое уменьшение изображений до 1600 px и JPEG 82%;
- проверка общего размера файлов до 4,5 МБ;
- индикатор отправки и красивые уведомления об успехе/ошибке;
- защита от спама: скрытое поле, проверка времени заполнения и ограничение частоты;
- PWA: сайт можно установить на телефон или компьютер;
- базовый офлайн-режим для уже открытых страниц и ресурсов;
- понятное сообщение вместо `Failed to fetch`, если HTML открыт двойным кликом.

## Важно

Настоящая отправка email и Telegram не может работать из адреса `file:///C:/...`.
Для формы нужен опубликованный сайт. В этом проекте используется Netlify Functions — PHP не требуется.

## Публикация на Netlify

1. Зарегистрируйтесь на Netlify.
2. Создайте новый сайт и загрузите всю папку `Forma_Stekla_Updated_2026` через Git или Netlify Drop.
3. Откройте: **Project configuration → Environment variables**.
4. Добавьте переменные из списка ниже.
5. Запустите новый deploy после добавления переменных.

### Переменные окружения

```text
WEB3FORMS_ACCESS_KEY=ваш_ключ_Web3Forms
TELEGRAM_BOT_TOKEN=токен_бота_от_BotFather
TELEGRAM_CHAT_ID=id_чата
NOTIFICATION_EMAIL=info.forma.stekla@gmail.com
```

Netlify передаёт эти значения только серверной функции. Не вставляйте токен Telegram в `index.html` или `app.js`.

## Настройка email

1. Создайте бесплатный access key в Web3Forms для адреса `info.forma.stekla@gmail.com`.
2. Подтвердите адрес письмом от Web3Forms.
3. Скопируйте ключ в `WEB3FORMS_ACCESS_KEY` на Netlify.

В email прикладывается первый файл. Если клиент добавил ещё файлы, все они также отправляются в Telegram.

## Настройка Telegram

1. Откройте `@BotFather` и создайте бота командой `/newbot`.
2. Скопируйте токен в `TELEGRAM_BOT_TOKEN`.
3. Напишите созданному боту любое сообщение.
4. Откройте в браузере:

```text
https://api.telegram.org/botВАШ_ТОКЕН/getUpdates
```

5. Найдите значение `message.chat.id` и сохраните его как `TELEGRAM_CHAT_ID`.

Для уведомлений в группе добавьте бота в группу, напишите сообщение и используйте ID группы.

## Локальная проверка

Двойной клик по `index.html` подходит только для визуальной проверки. Для полной проверки установите Netlify CLI и запустите:

```text
npm install -g netlify-cli
netlify dev
```

Перед запуском скопируйте `.env.example` в `.env` и вставьте реальные ключи. Затем откройте адрес, который покажет Netlify CLI, обычно `http://localhost:8888`.

## Ограничения вложений

- максимум 3 файла;
- общий размер после обработки — до 4,5 МБ;
- изображения уменьшаются в браузере;
- PDF не сжимается;
- Web3Forms получает первый файл, Telegram получает все файлы.

## Структура

- `index.html` — основной сайт;
- `assets/js/app.js` — форма, сжатие изображений, PWA и интерфейс;
- `netlify/functions/submit.mjs` — защищённая серверная отправка;
- `netlify.toml` — настройки Netlify;
- `site.webmanifest`, `sw.js` — установка сайта и офлайн-кэш;
- `.env.example` — список нужных секретных переменных.
